# Expungement Furance

This folder contains the source code for our expungement automation system.

When the program is running, it will wait for new data to be placed in the
/input directory.

Users will place raw data into the input folder with a specified schema. 
This data can be structured json or unstructured text data (like a PDF or similair).

The program will process the raw data and place the output in the /output directory.
